- <leader><leader> : find files
- <leader>/ : grep
- <leader>: : command history
- <leader>, : switch buffer
- <leader>fb : find in buffer
- <leader>fc : find config
- <leader>ff : git files
- <leader>fg : live grep
- <leader>fr : recent files in root dir
- <leader>fR : recent files in CWD
- <leader>sg : search grep in root
- <leader>sw : search word
- <leader>s" : register
- <leader>sk : keymaps
- <leader>sh : help pages


- Shift+h : prev buffer
- Shift+l : next buffer
- [b : prev buffer
- ]b : prev buffer
- <leader>bd : delete buffer
- <leader>bo : delete other buffer
- <leader>bp : toggle pin buffer
- <leader>bD : Delete buffer + window

- <leader>- : horizontal split
- <leader>| : vertical split
- <C-h> : Move left
- <C-j> : Move down
- <C-k> : Move up
- <C-l> : Move right
